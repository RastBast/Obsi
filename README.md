# Obsi

Учебные материалы для подготовки к техническим собеседованиям.

## Наборы карточек

- [220 карточек Go Middle с вводом ответа и FSRS внутри Obsidian](Golang-Middle-Interview/README.md)
- [Как пользоваться плагином «Карточки MAX»](Golang-Middle-Interview/Карточки-MAX-использование.md)
- [Установка на iPhone / iPad через iCloud](Golang-Middle-Interview/Мобильная-установка-iCloud.md)

Комплект использует собственный локальный плагин **«Карточки собеседования MAX»**: русский интерфейс, 9 колод, серия 🔥, прогресс пройденных/непройденных карточек, кнопка «Не знаю ответ» с полным показом заметки, честная пометка ответов после показа, лента ТТ со свайпами, лайками и комментариями и поддержка iPhone/iPad через iCloud. Отдельное приложение, Mochi и Star InfoLearn больше не нужны.
