Комплект использует собственный локальный плагин **«Карточки собеседования MAX»** (текущая версия **1.2.1**): русский интерфейс, папка `Карточки/` с темами-подпапками, 9 колод, серия 🔥, прогресс пройденных/непройденных карточек, кнопка «Не знаю ответ» с полным показом заметки, честная пометка ответов после показа, лента ТТ со свайпами, лайками и комментариями и поддержка iPhone/iPad через iCloud. Каждая `.md`-заметка в папке темы — это одновременно карточка и обычная заметка Obsidian. Отдельное приложение, Mochi и Star InfoLearn больше не нужны.

Быстрая проверка vault в iCloud Drive (ничего не копирует, печатает `✓/✗` по версии плагина, CSS, 9 темам и 220 заметкам):

```bash
cd .obsidian/plugins/interview-cards-max/scripts
./install-to-icloud.sh --check "/путь/к/вашему/vault"
```

Полный чек-лист — в [Мобильная-установка-iCloud.md](Golang-Middle-Interview/Мобильная-установка-iCloud.md#как-протестировать-за-5-минут).
