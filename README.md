# Obsi

Учебные материалы для подготовки к техническим собеседованиям.

## Наборы карточек

- [220 карточек Go Middle с вводом ответа и FSRS внутри Obsidian](Golang-Middle-Interview/README.md)

Комплект использует собственный локальный плагин **«Карточки собеседования MAX»**: русский интерфейс, 9 колод, серия 🔥, прогресс пройденных/непройденных карточек, кнопка «Не знаю ответ» с полным показом заметки и честная пометка ответов после показа. Отдельное приложение, Mochi и Star InfoLearn больше не нужны.
