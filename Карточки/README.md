# Карточки ← сюда кладём заметки

Это **единственная папка с карточками** в корне vault. Плагин «Карточки MAX» читает именно её.

## Правило простое

> Каждая `.md`-заметка внутри папки темы = **карточка** и одновременно **обычная заметка Obsidian**.

Можно просто перетащить сюда свои заметки — ничего переименовывать и не нужно настраивать. Заметка остаётся открываемой в Obsidian, а плагин показывает её в ленте и в повторении.

## Разделение по темам = папки

Каждая подпапка — тема (колода). Они же будут чипами в ленте:

| Папка | Карточек |
|---|---:|
| `Go/` | 43 |
| `Docker/` | 17 |
| `Kubernetes/` | 18 |
| `Сети/` | 26 |
| `Алгоритмы/` | 21 |
| `БД/` | 23 |
| `Рантайм/` | 37 |
| `Redis/` | 17 |
| `Kafka/` | 18 |

Хочешь новую тему — создай новую папку, например `Карточки/Моя тема/`, и положи туда заметки. Тема автоматически появится в панели колод и в ленте.

## Как заметка превращается в карточку

Плагин понимает **любую** Markdown-заметку:

- **Вопрос** = секция `## Вопрос`, либо первый абзац заметки, либо её заголовок/имя файла.
- **Ответ** = секция `## Краткий ответ`, либо всё содержимое заметки, если секций нет.
- Поддерживаются `## Развёрнутый ответ мидла`, `## Развёрнутый ответ сеньора: все тонкости`, `## Если забыл / Простыми словами`.
- **Тема** берётся из имени подпапки. Если в frontmatter указать `deck: Сети`, он имеет приоритет.
- `topic:` в frontmatter — необязательная подпись под вопросом.
- Тег `go` у базовых 220 карточек сохранён; у новых заметок он не обязателен.

Пример минимальной заметки `Карточки/Go/Мой вопрос.md`:

```markdown
---
deck: Go
tags: [go, interview]
---

# Чем map отличается от sync.Map?

sync.Map оптимизирован под «записал один раз — читал много» и под disjoint-ключи…
```

Она сразу станет карточкой, останется заметкой и попадёт в тему `Go`.

## Служебные заметки

Заметка с `icm-ignore: true` в frontmatter (как этот README) остаётся обычной заметкой, но **не** становится карточкой. Удобно для описаний папок.

## Старая папка

`Golang-Middle-Interview/Cards/` сохранена для совместимости. Плагин тоже её читает и склеивает с `Карточки/`, убирая повторы по тексту вопроса. Поэтому карточки не пропадут, даже если заметки пока лежат в старом месте.
