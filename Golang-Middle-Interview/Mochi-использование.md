# Как пользоваться карточками в Mochi

## Как проходит повторение

Каждая заметка начинается с вопроса и поля:

```markdown
===

@input
```

1. Прочитай вопрос.
2. Напиши свой ответ в поле `@input`.
3. Нажми встроенную кнопку Mochi **Далее**.
4. Сравни свой текст с кратким ответом.
5. Нажимай **Далее**, чтобы последовательно открыть уровень middle, senior-тонкости и объяснение простыми словами.

## Что делать, если не знаешь ответ

Markdown карточки не может добавить собственную программируемую кнопку с поведением Mochi. Поэтому используется штатный и надёжный сценарий:

1. Оставь `@input` пустым или напиши «не знаю».
2. Нажми **Далее** — откроется краткий ответ.
3. Продолжай до блока **Если забыл / Простыми словами**.
4. Прочитай аналогию, вернись к формулировке вопроса и произнеси новый ответ своими словами.
5. Оцени карточку как незапомненную, чтобы Mochi показал её раньше.

Таким образом `@input` заменяет отдельную кнопку ответа, а многосторонние разделители `---` дают поэтапное раскрытие материала.

## Почему не используется старый синтаксис `Вопрос::Ответ`

`Вопрос::Ответ` предназначен для плагина Obsidian Spaced Repetition. Mochi использует стороны карточки, разделённые строкой `---`. В этих заметках старый однострочный синтаксис удалён, чтобы он не создавал дубликаты и не смешивал два разных формата.

## Важное ограничение Mochi Cards Exporter

Плагин по ссылке `mochi-cards-exporter` версии 0.2.3 ищет строку с `#card` и прекращает чтение карточки на **первом** разделителе `---` или `***`. Поэтому он умеет экспортировать обычную двухстороннюю карточку, но не сохраняет несколько последовательных сторон из заданного шаблона.

Чтобы не потерять ответы middle, senior и аналогии, карточки оставлены в нативном многостороннем формате Mochi, а рядом добавлен локальный экспортёр `export_mochi.py`. Он собирает все стороны без сокращений в один `.mochi`-архив.

## Экспорт всех карточек

Из каталога `Golang-Middle-Interview` выполни:

```bash
python3 export_mochi.py
```

По умолчанию будет создан файл:

```text
Go-Middle-220.mochi
```

Его можно импортировать в Mochi через команду импорта формата Mochi.

Другой путь:

```bash
python3 export_mochi.py --output ~/Downloads/go-interview.mochi
```

Только проверить формат, ничего не создавая:

```bash
python3 export_mochi.py --check
```

## Формат одной карточки

```markdown
# Название темы

Вопрос

===

@input

---

## Краткий ответ

...

---

## Развёрнутый ответ мидла

...

---

## Развёрнутый ответ сеньора: все тонкости

...

---

## Если забыл / Простыми словами

...
```
