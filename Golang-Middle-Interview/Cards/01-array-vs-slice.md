# Чем массив отличается от среза?

## Вопрос

Чем в Go отличаются массив (`[N]T`) и срез (`[]T`)? Что именно копируется при передаче среза в функцию?

## Краткий ответ

Массив — значение фиксированной длины, длина входит в его тип. Срез — небольшой дескриптор над массивом: указатель на элементы, длина и ёмкость. При передаче в функцию оба значения копируются, но копия среза обычно указывает на тот же backing array.

## Развёрнутый ответ мидла

- `[3]int` и `[4]int` — разные типы; размер массива известен при компиляции.
- `[]int` не хранит элементы внутри себя. У него есть `ptr`, `len` и `cap`.
- `len(s)` — доступное число элементов, `cap(s)` — сколько элементов доступно от начала среза до конца backing array.
- Присваивание массива копирует все элементы. Присваивание среза копирует только дескриптор, поэтому изменение `s[0]` видно через другую копию среза.
- Изменение длины через `append` меняет только локальную копию дескриптора, пока новый срез не возвращён вызывающему коду.

```go
func add(s []int) []int { return append(s, 10) }

a := [3]int{1, 2, 3}
s := a[:]
t := s
t[0] = 9 // a[0] и s[0] тоже стали 9
s = add(s) // новый len нужно принять из результата
```

## Развёрнутый ответ сеньора: все тонкости

Спецификация описывает срез как значение, а не как «ссылочный тип». Его обычная runtime-реализация похожа на `struct { Data *T; Len, Cap int }`, но полагаться на внутреннее представление через `unsafe` не стоит. Нулевой срез `nil` имеет `len=0`, `cap=0`; пустой ненулевой срез обычно ведёт себя так же, кроме сравнения с `nil` и некоторых форматов сериализации.

Срез удерживает весь backing array достижимым для GC. Маленький subslice большого буфера способен надолго удержать мегабайты памяти. Если нужна независимая небольшая часть, её копируют: `dst := append([]T(nil), src...)` или `slices.Clone(src)`.

Полное выражение среза `a[low:high:max]` ограничивает ёмкость. Это полезно на границе API: `part := a[:n:n]` заставит следующий `append(part, ...)` выделить новый массив вместо перезаписи соседних элементов `a`.

Массивы сравнимы, если сравним их элементы, и могут быть ключами map. Срезы сравнимы только с `nil`. Компилятор может разместить backing array на стеке или в куче — это определяет escape analysis, а не сам факт использования среза.

## Если забыл: что это, зачем и где нужно

Срез — основной тип коллекции переменной длины в Go; массив чаще нужен как часть низкоуровневого формата, ключ map или буфер фиксированного размера. На собеседовании держи модель: **срез = указатель + длина + ёмкость; копируется заголовок, данные могут быть общими**. Это объясняет почти все вопросы про `append`, неожиданные изменения и удержание памяти.
