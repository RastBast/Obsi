# Как работают variadic-параметры?

## Вопрос

Что получает функция с параметром `...T`, как передать существующий slice и когда возникает aliasing?

## Краткий ответ

Внутри функции variadic-параметр имеет тип `[]T`. Можно передать отдельные аргументы или развернуть slice как `f(s...)`. При разворачивании функция получает slice, связанный с тем же backing array, поэтому мутация элементов может быть видна вызывающему коду.

## Развёрнутый ответ мидла

```go
func sum(xs ...int) int { /* xs — []int */ }
sum(1, 2, 3)
xs := []int{1, 2, 3}
sum(xs...)
```

- Variadic-параметр может быть только последним.
- Передача отдельных аргументов формирует slice для вызова; детали allocation оптимизирует компилятор.
- `append(dst, src...)` использует похожий синтаксис разворачивания.
- `nil` и отсутствие variadic-аргументов обычно дают nil slice, но API не должен без нужды зависеть от различия nil/empty.

## Развёрнутый ответ сеньора: все тонкости

- Изменение `xs[i]` внутри `sum(xs...)` меняет исходный slice; append может либо переиспользовать его массив, либо выделить новый.
- Variadic API удобен для небольшого необязательного списка, но плохо масштабируется для множества независимых options.
- `...any` теряет статическую типизацию, создаёт boxing и переносит ошибки формата в runtime.
- На hot path измеряют стоимость формирования arguments slice, а не предполагают allocation автоматически.

## Если забыл: что это, зачем и где нужно

`...T` снаружи означает переменное число аргументов, внутри — обычный `[]T`. `slice...` передаёт его элементы.

## Подробное объяснение простыми словами

Variadic-функция позволяет принести любое количество однотипных предметов. Внутри они лежат в одном списке. Если передан уже существующий список, функция может видеть те же элементы, поэтому менять их без явного контракта опасно.

## Подробное объяснение техническими терминами

Variadic parameter представлен slice value. Invocation с `s...` передаёт элементы существующего `[]T` без обязательного независимого копирования backing array. Семантика aliasing совпадает с обычными правилами slice; allocation остаётся оптимизацией компилятора.
