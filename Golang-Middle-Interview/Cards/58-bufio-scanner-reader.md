# Когда использовать bufio.Scanner, а когда bufio.Reader?

## Вопрос

Какие ограничения есть у Scanner, как увеличить размер token и почему ошибки проверяют после цикла?

## Краткий ответ

`Scanner` удобен для последовательных token по SplitFunc, но имеет максимальный размер token и прекращает работу при его превышении. Для больших строк, точного контроля буфера или сохранения delimiters используют `bufio.Reader`. После `Scan()` проверяют `Err()`.

## Развёрнутый ответ мидла

```go
s := bufio.NewScanner(r)
buf := make([]byte, 64*1024)
s.Buffer(buf, 1024*1024)
for s.Scan() { use(s.Text()) }
if err := s.Err(); err != nil { return err }
```

- По умолчанию Scanner разбивает по строкам и удаляет перевод строки.
- `Bytes()` может ссылаться на буфер, который изменится при следующем Scan; для долгого хранения нужна копия.
- Reader предлагает `ReadString`, `ReadBytes`, `ReadSlice`, `Peek` и полный контроль над ошибкой/разделителем.

## Развёрнутый ответ сеньора: все тонкости

- `Scanner.Buffer` вызывают до первого `Scan`; максимальный размер задают из protocol limits, а не безгранично.
- Custom SplitFunc обязана обеспечивать прогресс и корректно работать с `atEOF`, иначе возможны panic или loop.
- `ReadSlice` может вернуть фрагмент и `ErrBufferFull`; вызывающий собирает части либо выбирает другой API.
- Буферизация сокращает syscalls, но добавляет отдельный слой, который нужно flush при записи.

## Если забыл: что это, зачем и где нужно

Scanner — простой token loop с лимитом. Reader — больше контроля для больших или сложных протоколов.

## Подробное объяснение простыми словами

Scanner сам режет поток на строки или слова, поэтому код короткий. Но у него есть ограничение размера одного куска. Если вход может содержать огромную строку, лимит нужно осознанно увеличить или читать частями через Reader.

## Подробное объяснение техническими терминами

`bufio.Scanner` управляет reusable token buffer и вызывает SplitFunc над доступным prefix. Token lifetime ограничен следующей итерацией, а `ErrTooLong` защищает от unbounded allocation. `bufio.Reader` экспонирует более низкоуровневое управление delimiter и partial reads.
