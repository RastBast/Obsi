# Как правильно реализовать бинарный поиск?

## Вопрос

Какие инварианты цикла нужны, как найти первый подходящий элемент и где возникают off-by-one ошибки?

## Краткий ответ

Бинарный поиск работает по монотонному предикату на отсортированном диапазоне и за O(log n) сужает интервал. Удобный шаблон хранит полуинтервал `[lo, hi)` и ищет минимальный индекс, где predicate true.

## Развёрнутый ответ мидла

```go
lo, hi := 0, len(a)
for lo < hi {
    mid := lo + (hi-lo)/2
    if a[mid] < x { lo = mid+1 } else { hi = mid }
}
```

После цикла `lo` — lower bound; нужно проверить `lo < len(a)` и equality. Полуинтервал упрощает empty input и ответ `len(a)`.

## Развёрнутый ответ сеньора: все тонкости

- Главное условие — монотонность predicate: false...false,true...true.
- Формула mid избегает overflow в языках с ограниченной арифметикой; в Go индексы всё равно проверяют.
- Поиск по ответу применяет тот же шаблон к пространству решений.
- Comparator/order с NaN или несогласованностью ломает предпосылку.

### Дополнительное техническое объяснение

Binary search maintains loop invariant over half-open interval and monotone predicate. Each iteration halves cardinality, yielding O(log n); lower_bound returns partition point and требует postcondition validation.

## Если забыл / Простыми словами

Держи `[lo, hi)`, выбрасывай половину и после цикла проверяй границу.

### Аналогия и объяснение

Как поиск слова в словаре: открываем середину и сразу отбрасываем половину страниц. Важно заранее решить, ищем точное слово, первое не меньшее или последнюю допустимую страницу.
