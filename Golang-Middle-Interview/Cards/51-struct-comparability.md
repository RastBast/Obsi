# Какие типы в Go можно сравнивать?

Когда структура сравнима через `==`, какие значения можно использовать как ключ map и почему сравнение interface иногда паникует?

===

@input

---

## Краткий ответ

Тип сравним, если его значения поддерживают `==` и `!=`. Массивы и структуры сравнимы, только если сравнимы все элементы или поля. Slice, map и function несравнимы, кроме сравнения с `nil`. Динамическое несравнимое значение внутри interface делает сравнение interface причиной panic.

---

## Развёрнутый ответ мидла

- Сравнимы bool, числа, строки, указатели, channels, interfaces и составные типы из сравнимых частей.
- `[3]int` сравним, `[3][]int` — нет; `struct{ ID int }` сравним, структура со slice — нет.
- Ключ map обязан иметь сравнимый тип, потому что таблица проверяет равенство ключей после хеширования.
- Function можно сравнить только с `nil`; две функции сравнивать нельзя.

Generics используют constraint `comparable`, когда параметр станет ключом map или участвует в `==`.

---

## Развёрнутый ответ сеньора: все тонкости

- Сравнение interface сначала учитывает динамические типы, затем значения. Если одинаковый динамический тип несравним, возникает panic.
- `NaN` сравним синтаксически, но `NaN != NaN`; такой ключ map допустим, однако поиск и удаление становятся неожиданными.
- Сравнение структур может быть дорогим для больших массивов и строк, поэтому ключ выбирают по доменной идентичности, а не только по допустимости.
- Padding структуры не участвует в семантическом сравнении; полагаться на побайтовое представление через `unsafe` нельзя.

### Дополнительное техническое объяснение

Оператор равенства определён спецификацией для comparable types. Компилятор проверяет статический тип, а при сравнении interface выполняется runtime-проверка динамического типа. Constraint `comparable` ограничивает type set типами, допустимыми для equality и map key.

---

## Если забыл / Простыми словами

Проверь тип изнутри наружу: если каждое поле сравнимо, сравнима и структура. Slice, map и function сразу требуют другой стратегии.

### Аналогия и объяснение

Сравнимость отвечает на вопрос: можно ли однозначно сказать, что два значения одинаковы. Если структура содержит список, который сам нельзя сравнить одной операцией, всю структуру тоже нельзя сравнить. Тогда элементы сравнивают циклом или выбирают отдельный идентификатор.
