# Архив: как пользоваться карточками в Star InfoLearn

> ⚠️ **Это устаревшая инструкция.** Актуальный комплект работает через локальный плагин **«Карточки собеседования MAX»**: [установка, колоды и повторение](Карточки-MAX-использование.md). Star InfoLearn больше не требуется; его 220 JSON-карточек сохранены только как архивный экспорт.

## Почему ранее был выбран этот плагин

**Star InfoLearn** совмещает нужные функции в одном плагине Obsidian:

- тип карточки `short_answer` с многострочным полем свободного ответа;
- раскрытие введённого и эталонного ответа одной кнопкой;
- отдельное поле `explanation` для подробного разбора;
- оценки **Again / Hard / Good / Easy**;
- локальное интервальное планирование FSRS;
- работа на desktop и mobile без отдельного приложения для повторений.

Комплект подготовлен для Star InfoLearn **1.1.4**. Плагин зарегистрирован в каталоге Community plugins. Для готовых карточек не нужны AI-провайдер, API-ключ или внешний сервис.

## Установка как отдельного vault

Это самый простой и надёжный вариант.

1. Клонируй или скачай весь репозиторий.
2. В Obsidian выбери **Open folder as vault** и открой корень репозитория `Obsi`, а не только каталог `Golang-Middle-Interview`.
3. Открой **Settings → Community plugins → Browse**.
4. Найди **Star InfoLearn**, установи и включи плагин.
5. Открой **Settings → Appearance → CSS snippets** и включи `star-infolearn-go-middle`. Сниппет нужен только для удобного отображения длинных многоуровневых объяснений.
6. Запусти команду **Open Star InfoLearn** или нажми значок книги на ленте.
7. Если сразу не видно 220 карточек, на вкладке **Study** нажми кнопку обновления.

Готовые записи находятся в `.obsidian/plugins/star-infolearn/data/cards/`. Star InfoLearn загружает их напрямую; отдельный импорт и экспорт не нужны.

## Добавление в существующий vault

1. Сначала установи и включи **Star InfoLearn**.
2. Скопируй каталог `Golang-Middle-Interview` в корень своего vault.
3. Скопируй 220 JSON-файлов из `.obsidian/plugins/star-infolearn/data/cards/` комплекта в такой же каталог своего vault.
4. По желанию скопируй `.obsidian/snippets/star-infolearn-go-middle.css` и включи сниппет.
5. Перезапусти Obsidian или нажми обновление в разделе **Study**.

Пути `sourceFile` рассчитаны на расположение `Golang-Middle-Interview` в корне vault. Если положить каталог глубже, нужно так же изменить `sourceFile` во всех JSON-записях.

## Сценарий повторения

1. Открой Star InfoLearn и перейди в **Review**.
2. Выбери область повторения:
   - **All cards** — все карточки;
   - **Folder** — одна тематическая колода;
   - **Current note** — карточка открытой заметки.
3. Напиши свой ответ в поле **Enter your answer...**.
4. Если ответа не знаешь, оставь поле пустым и сразу нажми **Show Answer**.
5. После раскрытия плагин покажет:
   - **My answer** — введённый текст или `(not entered)`;
   - **Correct answer** — краткий эталон;
   - подробное объяснение с блоками **MIDDLE**, **SENIOR** и **ЕСЛИ ЗАБЫЛ / ПРОСТЫМИ СЛОВАМИ**.
6. Самостоятельно сравни смысл ответа с эталоном и выбери оценку:
   - **Again** — не вспомнил;
   - **Hard** — вспомнил с большим трудом;
   - **Good** — ответил достаточно хорошо;
   - **Easy** — ответил уверенно и без усилий.
7. Star InfoLearn обновит состояние карточки и дату следующего повторения по FSRS.

`short_answer` не пытается автоматически оценивать свободный русский технический текст. Это осознанная самооценка после сравнения с эталоном — без API и передачи ответа наружу.

## Девять колод

В Star InfoLearn 1.1.4 фильтр Review работает по исходной заметке и папке. Поэтому колоды представлены реальными подпапками `Cards`:

| Колода | Путь | Карточек |
|---|---|---:|
| Go | `Golang-Middle-Interview/Cards/Go` | 43 |
| Docker | `Golang-Middle-Interview/Cards/Docker` | 17 |
| Kubernetes | `Golang-Middle-Interview/Cards/Kubernetes` | 18 |
| Сети | `Golang-Middle-Interview/Cards/Сети` | 26 |
| Алгоритмы | `Golang-Middle-Interview/Cards/Алгоритмы` | 21 |
| БД | `Golang-Middle-Interview/Cards/БД` | 23 |
| Рантайм | `Golang-Middle-Interview/Cards/Рантайм` | 37 |
| Redis | `Golang-Middle-Interview/Cards/Redis` | 17 |
| Kafka | `Golang-Middle-Interview/Cards/Kafka` | 18 |

Дополнительно каждая Markdown-заметка и JSON-карточка содержит тег `flashcards/<Колода>`. Во всех 220 карточках используется общий тег `go`, а не `golang`.

## Где хранятся данные

- `Golang-Middle-Interview/Cards/<Колода>/*.md` — читаемые исходные заметки со всем учебным материалом.
- `.obsidian/plugins/star-infolearn/data/cards/*.json` — карточки `short_answer` и их состояние FSRS.
- `.obsidian/plugins/star-infolearn/data/logs/` — журналы повторений, которые плагин создаст локально.
- `.obsidian/plugins/star-infolearn/data/stats/` — локальная статистика, которую плагин создаст при работе.

После первого повторения Star InfoLearn обновляет `fsrsState` в JSON-файле карточки. Не заменяй изучаемые JSON-файлы их исходными версиями, если хочешь сохранить расписание.

## Реальные ограничения

- Кнопка **Show Answer** раскрывает краткий ответ и всё подробное объяснение за один шаг. Отдельных последовательных кнопок для middle и senior у Star InfoLearn 1.1.4 нет.
- Markdown внутри `explanation` показывается как текст. CSS-сниппет сохраняет переносы строк, списки и код читаемыми, но не превращает их в отрендеренный Markdown.
- Выбор тематической колоды делается через **Folder**, потому что текущий экран Review не фильтрует очередь по тегам.

Эти ограничения отражают фактическое поведение плагина; в заметках нет фиктивных Markdown-кнопок или неподдерживаемого синтаксиса.
